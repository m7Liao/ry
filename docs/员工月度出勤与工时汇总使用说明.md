# 员工月度出勤与工时汇总使用说明

更新日期：2026-10-27。沿用单体后端、Controller / Service / MyBatis、若依部门数据范围和 Vue3 / Element Plus 页面，不新增业务表，不改变已有考勤计算规则。

## 1. 使用入口

- 管理端：考勤管理 → 员工月度汇总，按月份、工号、姓名查询，每名员工一行，支持分页。
- 员工端：`/h5/daily` → 月度汇总，或直接访问 `/h5/monthly`，仅查看本人。
- 未登录访问员工端时，使用既有 H5 登录；登录后可安全返回月度页。

月份默认按上海时区取当前月；历史月份可查询，当月只统计至今天，未来月份拒绝。页面工时用小时显示，保留两位小数；接口以整数分钟返回，避免累加四舍五入后的小时数。

## 2. 统计口径

统计来源仅为 `att_daily_result`，不在查询时触发首次计算或重算。月份按考勤日期归属，夜班归属上班当天。

| 指标 | 口径 |
|---|---|
| 已生成天数 | 查询范围内已经保存的每日结果数 |
| 工作日天数 | 已生成结果中 `work_day=1` 的天数 |
| 已结算天数 | `NORMAL` 与 `ABNORMAL` 的合计 |
| 完整打卡天数 | 已结算、上下班均无缺卡且工时非空；允许迟到或早退 |
| 正常 / 异常 / 待结算 / 休息日 | 按每日结果状态分别统计 |
| 缺卡天数 | 已结算且任一方向缺卡；上下班均缺只计一天 |
| 迟到 / 早退天数与分钟 | 只统计已结算结果；待结算中的临时异常不计入 |
| 计划工时 | 已生成工作日的计划分钟合计，包含待结算和缺卡日 |
| 可核算日计划工时 | 仅完整打卡日的计划分钟合计，接口字段 `settledPlannedMinutes` |
| 已确认工时 | 已结算且上下班均不缺卡的非空计算分钟合计，不把缺卡或待结算的未知工时推断为0 |
| 工时待确认天数 | 已生成工作日中待结算、缺卡或工时为空的天数 |

页面“已确认工时”表示来自已结算且记录完整的计算结果，不代表人工审批、工资核算或加班认定。未知日不进入工时累计，并另外列出数量。因此工时合计为0时，应结合“工时待确认天数”阅读。

例：某员工一个月已生成5天，分别为正常、迟到早退、双缺卡、待结算、休息日。正常与迟到早退日各计算481分钟，工作日计划均480分钟：

- 已生成5天，工作日4天，已结算3天，完整打卡2天。
- 正常1天，异常2天，缺卡1天，待结算1天，休息日1天。
- 已确认工时962分钟，显示16.03小时；计划工时1920分钟；工时待确认2天。

未生成的日期不会自动算成缺勤。迟到、早退和缺卡可能重叠，不能把这些天数直接相加作为异常天数。查询无结果时显示空状态，不生成不存在的缺勤数据。

员工身份按员工ID合并；即使期间存在不同场所/部门快照，也不会按名称重复拆行。姓名、工号及部门显示当前查询范围内最近创建结果的快照，不表示员工当前组织归属。

## 3. 权限与历史数据

管理端新权限为 `attendance:monthly:list`，使用每日结果的部门和用户快照执行若依 `@DataScope`。角色配置为本部门时，仅聚合该部门可见结果；“仅本人”按结果 `user_id` 限定。前端隐藏菜单不能替代服务端权限检查。

管理端接口还支持 `siteId`、`deptId` 筛选，始终与数据范围同时生效。一个员工的部分历史结果不可见时，本行仅汇总可见部分，不显示其余结果的总数。

员工端复用 `attendance:checkin:submit`，不要求拥有管理端月报权限。先校验当前账号、员工档案及部门，再由服务端绑定当前登录用户。客户端提交的用户ID、部门、场所、姓名、工号或数据范围不能扩大本人查询。账号停用后旧Token不能继续查询。本人已保存的历史部门结果仍可查看。

返回仅含姓名、工号、部门展示文字、本人/被授权员工ID和汇总数字，不返回用户ID、规则JSON、加密人脸数据或计算人。

## 4. 安装与接口

先安装场所员工、规则及每日考勤模块，再执行 [attendance-monthly.sql](../Vue-springboot3/sql/attendance-monthly.sql)。本机开发库已执行，可重复执行；仅添加菜单及管理员授权，不新增表、不改写每日结果。单独月报增量不改变原37张表，另安装本次人脸增量后完整数据库为39张表。

普通角色需在“角色管理”授权月报菜单并配置数据范围，重新登录后生效。已有管理员可刷新菜单或重新登录。

| 接口 | 权限与响应 |
|---|---|
| `GET /attendance/monthly/list?month=2026-09&pageNum=1&pageSize=10` | 管理端月报权限；若依 `rows/total` 分页 |
| `GET /attendance/checkin/monthly?month=2026-09` | 员工签到权限；`data` 为本人汇总数组，当前最多一行，没有数据时为空 |

`month` 格式为 `yyyy-MM`，不传则默认当月；无效、早于1000年或未来月份拒绝。起止日期由月份在服务端生成，客户端不能扩大日期范围。管理端支持 `employeeNo/employeeName/siteId/deptId`。分页沿用框架行为，越界页码可能被规范到最后一页。
